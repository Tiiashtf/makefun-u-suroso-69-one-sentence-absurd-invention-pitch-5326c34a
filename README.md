One sentence, written by a program to `/output/entry.txt` — pitching a
toaster that saves breakfast from its oldest enemy, gravity:

> **A toaster that deploys a tiny parachute on any slice trying to land butter-side down, so breakfast floats gently to the plate, jam-side up.**

Toast always lands butter-side down, so the toaster fights back with a
parachute: the slice never gets the chance to flip, it just drifts down
jam-side up. The joke is the machine itself — a toaster that treats every
slice like a skydiver.

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13, standard library only, no network. It writes
`/output/entry.txt` (one sentence, 139 characters) and writes the same
bytes on every run; it clears only the contents of the output
directory, never the directory itself, and it refuses to write a line
outside the 1–220 character gate.
